# Graft GIS

Single-page marketing site for Graft GIS — *Where Land Meets Data*.

Static HTML/CSS/JS, no build step. Open `index.html` locally or serve via GitHub Pages.

## Pages and assets

- `index.html`: the landing page.
- `legal.html`: terms, privacy, and data sources and disclaimers. Linked from the footer and the lead form. Have counsel review it before launch.
- `assets/sample-report.pdf`: the sample branded report linked from the page. It is generated from `assets/sample-report.html`; the regenerate command is at the top of that file.
- `assets/img/qr-report.svg`: QR code for `https://graftgis.com/?ref=report`, used in the report footer.

The Houston demo map, MUD district summary, surge scenario panel, and MCP example use illustrative data. Each one says so on the page.
